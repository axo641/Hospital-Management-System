# Hopsital-Management-System (CPS714)

## Setup
1. in vscode's terminal -> git clone <repo-url> & cd Hospital-Management-System
2. then in the terminal -> python -m venv venv
3. Activate it (source venv/bin/activate, or venv\Scripts\activate on Windows)
4. run this command in terminal -> pip install -r requirements.txt
5. run this command in terminal -> python manage.py migrate
6. run this command in terminal -> python manage.py runserver
